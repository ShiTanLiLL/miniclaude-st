# 课程总览：从零造一个迷你 Claude Code

> 同学，欢迎你来。我是这门课的老师。
> 接下来的十八节课，我会牵着你的手，把一个"会自己干活的编程助手"从一行循环开始，一点点养成一个有工具、有权限、有记忆、有队友的完整 Agent。
> 你不需要是什么大神——只要你懂基础 Python 语法，剩下的，交给我。

---

## 一、我们要复现的是什么项目？

原项目叫 **learn-claude-code**（GitHub 上的开源教学项目），它做的事情说出来很简单，也很迷人：

**用 Python，从零复现 Claude Code 的"骨架"。**

Claude Code 你可能用过或者听说过——就是那个能在终端里帮你读代码、改文件、跑命令的 AI 编程助手。这个项目最打动人的观点是它 README 开篇那句：

> **智能来自模型，不来自编排代码。Agent 产品 = 模型（司机）+ Harness（车辆）。**

什么意思呢？大模型本身已经会思考、会决策了，工程师要造的不是"智能"，而是那辆车——给模型工具（手）、知识（眼睛）、权限边界（刹车）、上下文管理（油箱）。这辆车有个专门的名字，叫 **Harness**。

而整辆车的心脏，其实就一个小到不可思议的循环：

```python
while True:
    response = 调用大模型(messages, tools)
    如果回复里没有工具调用: 结束   # 模型自己决定什么时候停
    执行模型要用的工具
    把工具结果塞回 messages       # 再来一轮
```

原项目用 17 课，每课围绕这个循环加一种机制，最终拼出一台完整的 Agent 运行时。我们要做的，就是亲手把这辆车再造一遍——不是抄一遍哦，是**理解着造一遍**。

## 二、这门课怎么上

每节课都是固定四步，节奏由我控制，你只管跟着走：

1. **预习**（`预习.md`）：正式上课前的一小份轻松读物，聊聊下节课要解决什么问题、会遇到哪些新面孔（第三方库、新概念）。像课前聊天一样，没有压力。
2. **主教案**（`主教案.md`）：正课。我会讲清楚这节课在项目演化中的位置、带你逐段读懂新增代码、用一次真实的运行看看数据怎么流动、画图帮你建立全局感。
3. **复现代码**（`mini_claude/` 目录）：每节课我们的项目都会"长大一点"。你对照教案读代码里的增量，配合我给的阅读路线。
4. **总结**（`总结.md`）：下课后你自己复习用——上节课的流程图和伪代码、这节课的流程图和伪代码、以及"在哪加了什么"。复习时只看它就够了。

配套的还有两样东西：

- **每课一个 Git commit**：我们的代码仓库历史就是课程进化史，随时可以回看任何一步。
- **每课一套离线测试**：不用花一分钱 API 费用，用"假装是大模型"的假客户端就能验证每节课的机制真的在工作。想真实对话时，配一个 API key 就行（第 1 课手把手教你）。

## 三、课程地图（18 课 · 六个阶段）

我们的课程表尊重原项目的 17 章顺序（它本身就是精心设计的教学序列），最后加一节"毕业导航"收尾。

### 阶段一 · 让 Agent 动起来（第 1–4 课）
搭骨架、装手脚、上刹车、留扩展点。

| 课 | 主题 | 一句话 |
|---|---|---|
| 1 | Agent Loop | 一个 while 循环 + 一个 bash 工具 = 一个 Agent |
| 2 | Tool Use | 工具从 1 个变 5 个，循环一行都不用改（查表分发） |
| 3 | Permission | 执行前的三道闸：硬拒绝 → 规则 → 询问用户 |
| 4 | Hooks | 扩展点挂在循环外面，权限检查搬进 PreToolUse 钩子 |

### 阶段二 · 让 Agent 扛住复杂工作（第 5–8 课）
会做计划、会派分身、会查手册、会收拾上下文。

| 课 | 主题 | 一句话 |
|---|---|---|
| 5 | TodoWrite | 没有计划的 Agent 做着做着就跑偏 |
| 6 | Subagent | 给子任务一段全新的空白上下文 |
| 7 | Skill Loading | 知识用到时再加载，不是一股脑全塞 |
| 8 | Context Compact | 上下文总会满：四步压缩，先整理再总结 |

### 阶段三 · 让 Agent 记得住、跑得久（第 9–12 课）
跨会话的记忆、磁盘上的任务图、后台线程、定时闹钟。

| 课 | 主题 | 一句话 |
|---|---|---|
| 9 | Memory | 记住重要的、忘掉不重要的（选择/提取/整理） |
| 10 | Task System | 大目标拆成带依赖的小任务，存到磁盘 |
| 11 | Background Tasks | 慢操作丢后台，Agent 继续思考 |
| 12 | Cron Scheduler | 到点自动开工，不用人踢一脚 |

### 阶段四 · 多智能体协作（第 13 课，重头戏）
| 课 | 主题 | 一句话 |
|---|---|---|
| 13 | Agent Teams | 常驻队友 + 收件箱 + 原子认领 + 任务专属工作目录 |

### 阶段五 · 扩展与总装（第 14–15 课）
| 课 | 主题 | 一句话 |
|---|---|---|
| 14 | MCP Plugin | 能力不够？外接工具池，一个协议全通 |
| 15 | Integrated Harness | 整机检修：错误恢复、重试升级，所有机制一个循环 |

### 阶段六 · 编排与收尾（第 16–18 课）
| 课 | 主题 | 一句话 |
|---|---|---|
| 16 | Workflow Runtime | 固定的编排写进代码，断点还能续跑 |
| 17 | Goal Loop | 模型说"做完了"不算数，独立判断器说了算 |
| 18 | 毕业导航 | 不写新代码：原项目里没走到的地方，给你一张阅读地图 |

## 四、环境长什么样（预告，细节第 1 课讲）

- **语言**：Python 3.10+（第 1 课用 `uv` 工具三分钟配好虚拟环境，别怕）
- **依赖**：全程只有 3 个第三方库——`anthropic`（调模型的 SDK）、`python-dotenv`（读配置）、`pyyaml`（第 7 课才登场），按课逐步引入
- **模型**：需要一个大模型 API（Anthropic 官方，或 GLM/Kimi/DeepSeek 等兼容接口都可以）；**没有 key 也完全能上课**——我们的测试用假模型离线跑
- **其他**：没有数据库、没有 Docker，所有持久化都是本地文件。干净得很。
